# tobitate-takopa

イベント主催者用のページ（GitHub Pages）。参加者・料金・会計・買い物リスト・イベント情報を、主催者の複数の端末で共有して編集する。

- 公開ページ: https://kzt-fuku.github.io/tobitate-takopa/

## 個人情報の扱い

このリポジトリは公開なので、**参加者の情報やイベント固有の内容は一切置かない**。
データ（`data.json`）は非公開リポジトリ `kzt-fuku/tobitate-takopa-data` にあり、ページは合言葉（GitHub のトークン）を入れた端末だけが GitHub API で読み書きする。

- 合言葉は端末のブラウザ（localStorage）にだけ保存され、このリポジトリやページには含まれない
- テスト用の `test/fixtures/data.json` は架空のデータ

## 使い方

1. ページを開き、合言葉を入力する（端末ごとに初回だけ）
2. 編集すると画面下に「保存していない変更があります」と出る。「保存」でほかの端末にも反映される
3. ほかの端末が先に保存していた場合は、上書きせずに「最新を使う／この端末の変更で上書き」を選ぶ
4. 保存前の変更は端末内に下書きとして残るので、再読み込みしても消えない

## 計算ルール

- 宿泊は1泊ごと。11日に泊まる人は自動でたこパ参加（宿泊者のたこパ料金）。12日のみの人はたこパに参加しない
- 収入から会場代を引き、残りを食費（買い物リスト。実際の金額を優先、なければ予定金額）とその他の費用に充てる
- 不足したら、確定した大学生以上の全員で均等に割る（10円未満切り捨て）
- 余ったら、①主催者の宿泊費1泊分を無料 ②さらに余れば宿泊者全員の宿泊費を均等に割引（10円未満切り捨て、宿泊費が上限）
- キャンセル料は、「キャンセル料あり」の人の固定料金（宿泊・たこパ・スイーツ）の50%
- 「確定のみ」と「未確定も含む見込み」を切り替えて見られる

## 構成

```
docs/                 GitHub Pages の公開元（main ブランチの /docs）
  js/config.js        データの置き場所（非公開リポジトリ名）
  js/calc.js          料金・会計の計算（Node のテストからも使う）
  js/store.js         GitHub API での読み込み・保存、競合検出、端末内の下書き
  js/ui.js            共通部品（編集シート・トーストなど）
  js/view-*.js        各タブ（参加者・会計・買い物・情報）
  js/app.js           起動・合言葉・タブ・保存バー
test/calc.test.js     計算のテスト
tools/check-ui.mjs    画面の動作確認（GitHub API はモック、375px / 390px）
tools/check-live.mjs  公開ページと本物の GitHub API での確認（一時ブランチを使う）
```

## 開発

```sh
npm install
npm run check        # 計算のテスト + 画面の動作確認
TAKOPA_TOKEN=... npm run check:live   # 公開ページ × 本物の API（一時ブランチで試し、本番データは変更しない）
```

バージョンは `docs/index.html` の `<meta name="app-version">` と、css / js の `?v=` を同じ値にする（更新時に古いファイルがキャッシュから使われないようにするため）。
